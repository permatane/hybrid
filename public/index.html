VECTORICH STUDIO

Panduan & standar pemeriksaan

Ponsel: gunakan tab bawah untuk berpindah panel. Geser deretan alat untuk melihat semua alat. Cubit/renggangkan dua jari untuk zoom dan geser dua jari untuk pan. Pilih Pan untuk geser satu jari dan gunakan slider tegak di tepi preview untuk zoom. Klik ganda slider untuk menyesuaikan artboard. Pilih banyak menambahkan objek ke seleksi; Isi grup memilih bentuk di dalam grup. Ketuk dua kali node untuk menghapusnya.

01 / Impor SVG

Buka campuran SVG, PNG, JPEG, atau WebP melalui satu tombol Impor file, atau seret ke kanvas. Untuk raster, Hapus warna area membuat warna yang terhubung pada titik klik menjadi transparan; ubah toleransi lalu gunakan Undo/Redo bila tepi kurang tepat. Ikon hapus warna, kuas, Undo/Redo, dan Reset berada di atas preview; ukuran kuas mendatar di kiri atas preview. Ketuk ikon edit yang sedang aktif untuk kembali ke Pan. Zoom raster tersedia melalui slider tegak di kanan preview dan gulir; klik ganda slider untuk menyesuaikan gambar. Di editor vektor, panel QC berada di kanan desktop dan tersedia melalui tab QC di ponsel. Semua opsi ekspor vektor ada di menu Ekspor pada bagian atas. Pilih tab dokumen untuk mengedit dan melihat QC masing-masing. Gambar raster memakai panel koreksi dan ekspor PNG/JPEG; SVG dapat dirasterisasi melalui tombol SVG → PNG/JPEG. Raster → SVG membuat path warna solid dengan detail terbatas dan perlu perbaikan visual. Periksa semua memperbarui skor setiap file. Perubahan dan Undo/Redo tersimpan terpisah selama sesi. AI dan EPS harus diekspor ke SVG melalui Illustrator atau Inkscape. Fitur aktif dan resource eksternal diblokir saat impor.

02 / Periksa & pilih

Klik temuan QC untuk memilih objek terkait. Pilih profil tujuan; angka MP memakai ukuran dokumen dalam px, bukan jumlah node.

03 / Edit vektor

Q pilih & geser · W node · E seleksi kotak · R potong area · S hapus warna · A geser kanvas · Z drag kotak untuk zoom area · D kembali ke 100% · X zoom out. T Pisahkan area: klik bagian isi tertutup dalam path gabungan untuk membuat objek tersendiri, lalu ganti Fill di Properti. Area tunggal langsung dipilih. Mendukung warna solid tanpa stroke/clip/mask/filter; lubang transparan tetap dipertahankan. Tidak membuat batas baru pada area yang belum memiliki subpath tertutup. H Halo: tumpukan atau halo tepi lokal. Untuk halo tepi, klik objek utama lalu Cari otomatis dan klik di dekat garis; toleransi klik layar membantu memilih garis sangat tipis. Pilihan manual tetap ada. Atur kompensasi dan radius. T Trim · Y Pisahkan area. Ctrl G Group hasil seleksi kotak; Ctrl U Ungroup. Q memilih grup, Alt+klik memilih isi grup; W mengedit node bentuk di dalam grup. Dengan seleksi aktif, R dan S hanya memotong objek dalam seleksi. Group menggabungkan objek pada satu parent/layer di posisi objek teratas yang dipilih. Ungroup melepas objek langsung ke layer induk, mempertahankan transformasi dan warna. Tahan Shift + drag untuk pan sementara; lepaskan Shift untuk kembali ke alat aktif. Shift + klik pada daftar layer untuk multi-pilih. Drag node atau handle; klik ganda titik node untuk menghapusnya, klik ganda path untuk menambah node. Ctrl+Z untuk membatalkan. Seleksi kotak mengurung objek; tahan Alt untuk memilih yang bersinggungan. Tekan Enter untuk menerapkan kode warna.

04 / Simpan hasil

Ctrl C salin objek/area/grup · Ctrl V tempel salinan dengan sedikit offset. Clipboard objek berlaku di aplikasi ini selama sesi browser. Ctrl Z undo · Ctrl Shift Z redo · Delete hapus seleksi. Menu Ekspor berisi SVG, EPS, JPG preview, dan laporan QC untuk dokumen aktif; pilih dokumen lain untuk mengekspornya secara terpisah. EPS hanya untuk path vektor solid tanpa transparansi, raster, teks, gradien, filter, atau clipping. Ekspor JPG preview bernama sama untuk unggahan Freepik. Periksa EPS di editor vektor; Shutterstock mewajibkan penyimpanan ulang sebagai Illustrator EPS 8/10. Laporan QC tersedia dalam JSON per dokumen.

Metadata C2PA

Tombol Metadata memungkinkan melihat manifest asal, menyimpan payload mentah, mengedit keterangan SVG terpisah, menghapus C2PA saja, atau menghapus seluruh metadata. Manifest bertanda tangan tidak diubah dalam editor; verifikasi/tanda tangan ulang memerlukan alat C2PA khusus. Metadata bukan bukti valid jika artwork sudah diedit.

Impor arsip ZIP

Pilih tombol Impor file atau seret ZIP ke editor. Semua SVG, PNG, JPG/JPEG, dan WebP yang didukung di dalam ZIP, termasuk dari subfolder, akan dibuka sebagai dokumen terpisah. File lainnya dilewati. Arsip diproses secara lokal tanpa diunggah.

Batas pemeriksaan

Path terbuka, objek kecil, duplikat, dan kepadatan node adalah heuristik untuk ditinjau, bukan larangan otomatis. Stroke terbuka bisa disengaja. Bentuk bertumpuk, clipping, font, profil ICC, kualitas kurva, hak cipta, merek, release, dan deklarasi AI perlu pemeriksaan manusia. Fitur Halus dan Sederhanakan dapat mengubah siluet; gunakan undo bila perlu.

Potong bebas mengiris bentuk mengikuti garis yang digambar seperti pensil. Gambar mengelilingi bagian yang ingin dipisah, lepaskan untuk membuat dua path mandiri. Pilih bagian hasil potong dan tekan Delete jika ingin menghapusnya. Berlaku untuk bentuk solid tertutup tanpa stroke, mask, clip, filter, atau transform CSS. Pilih objek target dahulu; tanpa seleksi, bentuk yang bersinggungan menjadi target. Objek yang tidak didukung akan dilewati dengan pemberitahuan. Trim: klik objek kecil yang menutup bidang lain untuk memotong bentuk objek utama di belakangnya menjadi lubang asli, lalu menghapus objek pemotong. Sebelum Trim, pilih tepat satu objek utama jika ingin membatasi target. Tidak bekerja pada stroke/clip/mask/filter atau bentuk yang tidak bertumpuk. Undo (Ctrl+Z) memulihkan keduanya. Hapus area (S): klik isi warna solid untuk membuat lubang transparan; objek utuh dihapus langsung, sedangkan warna di bawahnya dipotong dengan toleransi kecil anti-hairline. Objek di depan dipertahankan. Area mengikuti komponen path, bukan seleksi piksel; bagian yang terhubung dalam satu path dapat ikut terhapus. Stroke, teks, raster, simbol, clip, mask, dan filter yang bersinggungan perlu dikonversi terlebih dahulu; operasi dibatalkan jika tidak didukung. Ctrl+Z membatalkan. File SVG kompleks tetap mempertahankan struktur aslinya saat operasi tidak tersedia.
